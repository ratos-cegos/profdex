# Regras do Repositório

## Natureza do projeto

- A landing page é **estritamente uma vitrine pública de marketing** para a Semana Tecnológica.

## Proibição de vazamento técnico

- É **estritamente proibido** expor termos de arquitetura interna nos textos visíveis ao usuário final, incluindo, por exemplo:
  - `seed do banco`
  - `Vue`
  - `NestJS`
  - `Three.js`
  - `GLB`
  - `APIs`

## Fluxo de negócio

- O fluxo de captura de QR Code deve sempre refletir a interação real no estande do evento.
- A interface **não deve expor regras de validação de backend**.

## Commits

- As mensagens de commit devem ser **claras, semânticas e em português**.
